## Setup

You need a JDK (17 or newer). Maven is downloaded by the wrapper.

```bash
./mvnw test                     # Windows: mvnw test
```

## Running

```bash
./mvnw -q compile exec:java
# or
./mvnw package
java -jar target/sensorlab-1.0.jar
```
